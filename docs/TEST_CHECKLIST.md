### 异常情况
- [ ] 未选择文件点击计算 → 显示错误提示

- [ ] 网络断开保存批注 → 显示错误提示
- [ ] 文件路径不存在 → 显示错误提示

- [ ] 文本块无参考匹配 → 显示"无匹配"

- [ ] 文本超长 → 正确截断显示
