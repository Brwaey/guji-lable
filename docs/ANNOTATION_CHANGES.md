## ⚠️ 重要提醒

### 1. **双向选择规则**
- **识别错误** → 必须选择OCR文本
- **缺失内容** → 必须选择参考文本
- **多余内容** → 必须选择OCR文本
- **其他问题** → 可选择任一侧

### 2. **保存时机**
- 点击"保存批注"立即保存到服务器
- 切换文本块前确保保存完成
- 未保存的选择会丢失

### 3. **性能建议**
- 大文件（>1000块）建议每页100条
- 避免同时打开过多文本块
- 定期导出备份批注数据
