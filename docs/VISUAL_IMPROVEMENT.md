# 批注界面视觉改进说明

## 🎯 用户反馈问题

### 问题1：批注时看不到完整文本对比
**用户反馈**："批注怎么不能同时看到完整的ocr文本和参考文本了。。这样用户怎么好批注嘛"

**原因**：
- 根据标注类型只显示一侧文本
- "缺失内容"只显示参考文本
- "识别错误"只显示OCR文本
- 用户无法对比查看

**解决方案**：
```
✅ 始终显示双侧文本对比
✅ 智能提示哪一侧可选择
✅ 未选择侧显示但禁用选择
✅ 背景颜色区分可选择状态

布局：
┌─────────────────────────────┐
│  文本对比                    │
├──────────┬──────────────────┤
│ OCR文本  │ 参考文本          │
│ ←点击选择│ ←点击选择         │
│ [可选择] │ [根据类型可选择] │
└──────────┴──────────────────┘
```

---

### 问题2：颜色太多，看不懂含义
**用户反馈**："那些文本块为什么五颜六色的，每种颜色都啥意思也看不出来"

**原因**：
- 使用了多个背景色（绿色、黄色、红色、蓝色）
- 没有颜色图例说明
- 视觉干扰过大

**解决方案**：
```
✅ 添加顶部颜色图例
✅ 统一背景为白色（减少干扰）
✅ 只用边框颜色区分质量
✅ 相似度数字加颜色标记

颜色图例：
🟢 绿色边框 = 高质量 (≥85%)
🟡 黄色边框 = 中等质量 (70-85%)
🔴 红色边框 = 低质量 (<70%) ← 优先批注
🔵 蓝色边框 = 已批注
🔵 粗蓝边框 = 当前选中

视觉效果：
- 背景统一白色，清爽干净
- 边框颜色清晰标识质量
- 数字颜色加强对比
- hover时显示阴影提示可点击
```

---

## 🎨 新视觉设计

### 文本块卡片样式
```css
/* 背景统一 */
background: white;

/* 边框颜色区分 */
高质量: border-2 border-green-300
中等: border-2 border-yellow-300  
低质量: border-2 border-red-300
已批注: border-2 border-blue-400
选中: border-2 border-primary-500

/* hover效果 */
hover:shadow-md（提示可点击）
```

### 批注面板文本对比区
```css
/* OCR文本 */
正常: bg-gray-50 border-gray-300
可选择: hover:border-primary-400（提示可选择）
禁用选择: bg-gray-100 text-gray-400（灰色显示）

/* 参考文本 */
正常: bg-gray-50 border-gray-300
缺失模式可选择: bg-green-50 border-green-300（绿色背景）
```

## 📝 使用说明

### 查看颜色含义
在页面顶部找到颜色图例：
- 🟢 绿色边框 = 高质量，无需批注
- 🟡 黄色边框 = 中等质量，可选批注
- 🔴 红色边框 = 低质量，**优先批注**
- 🔵 蓝色边框 = 已批注，查看详情

### 批注时查看对比
在批注面板右侧：
1. 同时看到OCR和参考文本
2. 根据标注类型选择文本：
   - "识别错误" → 在左侧OCR文本选择
   - "缺失内容" → 在右侧参考文本选择
3. 对比查看更容易判断错误

### 快速定位优先级
扫描文本块列表：
- 红色边框优先处理
- 黄色边框次优先
- 绿色边框可跳过
- 蓝色边框已完成
